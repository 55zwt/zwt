JavaScript 六种基本数据类型

JavaScript 的数据类型分为六大类：字符串、数值、布尔、未定义、空值、对象。 使用 typeof 关键字可以检测一个值的数据类型。下方每张卡片演示一种类型的定义方式与检测结果。

小贴士：
① typeof null 返回 "object" 是 JavaScript 的历史遗留 bug，实际 null 是独立的空值类型；
② 数组和函数在 typeof 看来都是 object，但它们是 object 的特殊子类；
③ ES6 新增了 Symbol 和 BigInt 两种原始类型，现代项目中也会用到。
