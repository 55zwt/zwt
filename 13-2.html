13-2 · Lucide SVG 图标

本页用 SVG 方式显示图标：图标是矢量图形文件，来自本地 cdn/lucide/icons/*.svg。页面里同时演示三种用法——<img src="cdn/lucide/icons/house.svg">、内联 <svg>、以及 CSS mask 把 SVG 当遮罩上色。

CSS3 3D 动画 · 图标旋转环

八个 SVG 文件沿 rotateY + translateZ(9rem) 排成一圈，容器 preserve-3d 持续旋转。

方式一 · img 引用 SVG 文件

直接把 cdn/lucide/icons/ 目录下的 16 个 .svg 文件作为图片引入，线条颜色是文件里写好的 stroke="currentColor"（在图片环境下呈现为黑色，所以放在浅色卡片上）。

方式二 · 内联 SVG

把 SVG 代码写进 HTML，stroke="currentColor" 让图标继承文字颜色，改变的是矢量路径，不会失真。

40px

方式三 · CSS mask 用 SVG 上色

mask-image 指向本地 SVG 文件，用 background-color 决定颜色，同一份文件可以染出任意颜色。

本地文件：cdn/lucide/icons/ 下 16 个 .svg，来自 lucide-static v0.469.0（ISC 协议），全部下载到本目录，不使用在线 CDN。

与字体图标对比：SVG 每个图标是独立文件，能直接改 stroke、fill、mask 上色；字体图标则像文字，靠字号和文字颜色控制。
